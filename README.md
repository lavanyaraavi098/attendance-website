# Attendance Website

A simple and user-friendly web application for calculating and tracking student attendance.

## Live Demo

https://attendence-website-xi.vercel.app/

## About the Project

The Attendance Website helps students calculate their attendance percentage based on the number of classes attended and the total number of classes conducted.

It provides a simple interface that makes attendance calculation quick and easy.

## Features

- Calculate attendance percentage
- Enter total classes conducted
- Enter classes attended
- Display attendance percentage instantly
- Simple and user-friendly interface
- Responsive design for different screen sizes

## Technologies Used

- HTML
- CSS
- JavaScript
- Vercel
